chloro

rustfmt's output in a fraction of the time.

chloro formats Rust several times faster than rustfmt, in a fraction of the memory, and writes the same bytes as rustfmt --edition 2024. It is a module-by-module port of rustfmt 1.9.0's formatting code onto the syntax trees of rust-analyzer's parser, so it does not need the Rust compiler. It comes as a 2 MB command-line tool and as a library.

Getting started¶

cargo binstall chloro          # or: cargo install chloro --features cli
chloro --check src/            # exit 1 if any file would change
chloro --write src/            # format in place

let formatted = chloro::format_source("fn main(){let x=1;}\n");
assert_eq!(formatted, "fn main() {\n    let x = 1;\n}\n");

Compatibility with rustfmt¶

chloro's formatting modules follow rustfmt's source files (items, expr, chains, lists, comment and so on), so each formatting decision can be checked against the rustfmt code it comes from. Any output that differs from rustfmt's is a bug; the known differences are listed.

It takes rustfmt's stable options under their rustfmt names (max_width, tab_spaces, use_small_heuristics, edition, style_edition and the rest), from rustfmt.toml and --config key=value on the command line or on a Config in the library, and takes each crate's edition from its Cargo.toml as cargo fmt does. Unstable options keep their default values. By default it reproduces rustfmt 1.9.0; with rustfmt_version = "1.8.0" it reproduces rustfmt 1.8.0, the release shipped with Rust 1.88.

The command line is not a replacement for the rustfmt binary: chloro has no --emit modes, and formats standard input only with --stdin. rustfmt compatibility lists the other differences.
